Privacy Policy

Effective date: 2026-01-01

1. Who we are

This application ("the App") is a personal-use instance of the open-source tool rclone, operated by an individual for their own file synchronization between cloud storage and their private servers. The App has no website of its own beyond this documentation page, has no employees, and offers no services to third parties.

2. Data we collect

The App itself does not collect, transmit, or store any personal data on any server we control. Specifically:

  • No usage analytics, no tracking, no cookies, no advertising.
  • Google Drive content: the App reads and writes files and metadata in the Google Drive account that you explicitly authorize, solely to perform the synchronization operation you configured. File contents and metadata are transferred directly between Google's servers and the machine where you run the App.
  • Authentication tokens: when you grant access, Google issues OAuth tokens (including a refresh token). These tokens are stored only in the local rclone configuration file on the machine where you run the App, protected by the operating system's file permissions. They are never sent anywhere other than Google's own OAuth and Drive APIs.
  • Log files: if you enable rclone logging, logs are written locally to a file path you choose and may contain file names processed during the sync. These logs never leave your machine unless you configure them to.

3. How we use data

Any data processed by the App is used for exactly one purpose: performing the file synchronization you configured between your Google Drive account and your own machine. There is no other use.

4. Data sharing

We do not sell, rent, share, or disclose any data to any third party, because no data is collected by us in the first place. The only third party involved in any data processing is Google LLC itself, in its capacity as the provider of the Drive service and the OAuth authorization service, under Google's own privacy policy. The App embeds no third-party SDKs, fonts, or external resources.

5. Data retention and deletion

  • Local files synced by the App remain under your control on your own machine; deleting them is done via the App or your operating system.
  • OAuth tokens are stored only in the local rclone configuration file; you can delete them at any time by removing the remote from your rclone configuration.
  • You can revoke the App's access entirely at any time at https://myaccount.google.com/permissions.

6. Security

Tokens and configuration are stored locally and are protected by the operating system file permissions of the account running the App. The App communicates with Google only over HTTPS.

7. Changes to this policy

If this policy changes, the updated version will be published on this page.

8. Contact

For any question about this policy, open an issue in the GitHub repository hosting this page: https://github.com/qsgy-edge/rclone-home.
