rclone

rclone is an open-source command-line tool that synchronizes files between cloud storage and your own machines. This page is the home page of a personal-use instance of rclone, used by its owner to back up and sync their own files between Google Drive and their private servers.

How it works

  • You authorize access to your own Google Drive account via Google's OAuth consent screen.
  • The tool transfers files directly between Google's servers and the machine where it runs. No third-party server is involved.
  • Authentication tokens are stored only in the local configuration file on your machine.
